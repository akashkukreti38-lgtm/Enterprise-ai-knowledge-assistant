# Enterprise AI Knowledge Assistant

An AI-powered enterprise knowledge management system that enables users to interact with organizational documents using natural language.

## Project Objective

Organizations store important information across multiple documents such as HR policies, employee handbooks, SOPs, technical documentation, and user manuals. Searching through these documents manually is time-consuming.

This project aims to simplify information retrieval by allowing users to upload documents and ask questions in natural language. The system retrieves relevant document sections and generates accurate, context-aware responses using Retrieval-Augmented Generation (RAG).

---

## Features

- User Authentication
- Secure Document Upload
- PDF Processing
- Semantic Search
- AI-powered Question Answering
- Source Citation
- Chat History
- Multi-document Support
- REST APIs
- Responsive User Interface
